# ComponentGalleryAI

Modern AI Frontend Assistant (Web PC) — Vue 3 + Vite + TypeScript + UnoCSS.

## Quick Start

```bash
pnpm install
pnpm run dev
```

Open `http://localhost:5173`.

## Notes

- The app calls `POST /api/generate`.
- Dev mode includes a built-in mock endpoint (Vite middleware) so the project runs with one command.
- Replace the mock with your real backend when integrating an actual LLM.
